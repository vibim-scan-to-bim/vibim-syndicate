Navisworks Reference: Editions, File Formats, and Core Tools

This reference sheet summarizes what Autodesk Navisworks does, which edition covers which task, and how the main tools fit together in a coordination workflow. It is written for BIM coordinators and project teams who need a quick lookup rather than a long tutorial.

Definition

Navisworks is a project review application from Autodesk. It does not author design geometry. Its job is model aggregation: it merges 3D models from different disciplines and software into one federated model that the team can inspect, simulate, and mark up. Autodesk acquired it in 2007 from the UK-based company NavisWorks Ltd.

Edition comparison

Edition Clash detection 4D/5D simulation and quantification Editing or analysis Best fit
Manage Yes (Clash Detective) Yes Full toolset BIM managers, coordinators
Simulate No Yes Review features Estimators, schedulers, project managers
Freedom No No Viewer only (NWD and DWF) Clients and stakeholders without a license

Core tools and what each one does

Tool or feature Purpose
Model aggregation Combines data from over 60 file formats into a single model
Clash Detective Finds, inspects, and reports geometric interferences between disciplines
TimeLiner Links model geometry to schedule data for 4D and to cost data for 5D
Quantification Produces material quantities and measurements from 3D models or 2D sheets
Rendering Creates photorealistic images and animations, locally or in the cloud
Walk-through navigation Lets reviewers move through the aggregated model in real time
Markup Adds measurements, redlines, and comments to saved viewpoints

Native file formats

  • NWC: one of the three native formats.
  • NWF: supports real-time model updates.
  • NWD: supports secure, milestone-specific snapshots.

Choosing between live references (NWF) and fixed snapshots (NWD) lets a team decide whether reviewers see real-time updates or a stable milestone state.

Typical workflow steps

  1. Collect models from each discipline, such as architectural, structural, and MEP, in their native formats.
  2. Append them into one Navisworks session to build the federated model.
  3. Run clash tests in Manage and review each interference with the responsible discipline.
  4. Link the model to the project schedule in TimeLiner to check the construction sequence.
  5. Export quantities for takeoffs and share an NWD snapshot with stakeholders who use Freedom.

Relationship to Revit

Revit and Navisworks are complementary. Revit creates parametric models and construction documents. Navisworks reviews and coordinates models that were already created elsewhere. A clash report is only as reliable as the models behind it, so input quality decides how useful the review will be.

Cloud connection

Navisworks connects with Autodesk Construction Cloud and BIM 360, so teams can open and review models hosted in a shared data environment.

Quick answers

  • Can Navisworks open IFC? Yes, along with RVT, DWG, and its own NWF, NWD, and NWC formats.
  • Is it a BIM tool? Yes, but its role is review, analysis, and coordination rather than design authoring.
