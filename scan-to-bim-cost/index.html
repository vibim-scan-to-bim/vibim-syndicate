Scan to BIM Cost: Technical Reference

This reference lists the variables, ranges and formulas used to estimate the cost of converting 3D laser scan data into a BIM model. All figures describe the U.S. market and are estimates, not quotes.

1. Definitions

  • Scan to BIM cost: total spend to produce a building information model from laser scan data. It combines scanning and modeling.
  • Point cloud registration: aligning individual scans into one coordinate system before modeling starts.
  • LOD (Level of Development): the amount of geometric and data detail a model element carries. LOD 200 shows approximate geometry. LOD 300 and 350 give precise as-built geometry.
  • Lump sum: a single fixed price for a defined scope.

2. Phase cost ranges

Phase Typical U.S. range
3D laser scanning $2,000 to over $10,000
Point cloud to BIM modeling $2,000 (simple) to over $20,000 (large, complex)

3. Hourly rate reference

Task Rate per hour
On-site laser scanning $150-$500
Registration and processing $75-$150
Revit modeling from point cloud $50-$125
Senior BIM manager or QA $100-$175

Offshore providers may quote $30-$60 per hour but can need more project management and quality oversight.

4. Worked formula

Modeling cost = (processing hours x processing rate) + (modeling hours x modeling rate).

Example: 8 hours at $100 plus 40 hours at $75 gives $800 + $3,000 = $3,800 for the modeling phase, excluding scanning.

5. Cost drivers, in the order they usually bite

  1. Gross area and number of stories
  2. Architectural and MEP complexity
  3. Target LOD (LOD 200 to 300 can add 30-50% modeling time)
  4. Point cloud density and gaps
  5. Output formats: RVT, DWG, IFC, FM-ready data
  6. Delivery deadline
  7. Provider specialization

6. Estimation procedure

  1. Record gross area, stories and building type.
  2. Choose the target LOD per discipline.
  3. Confirm point cloud format and coverage.
  4. List every deliverable file type separately.
  5. Pick a pricing model: per square foot for early budgets, hourly for open scope, lump sum for fixed scope.
  6. Request the quote with the area, LOD and deliverable list attached.

7. Rework context

The Construction Industry Institute reports rework at 5-12% of total project cost. A verified as-built model is one way to reduce that exposure.
