COBie Technical Reference for BIM Handover

This reference summarizes the COBie data standard as it applies to BIM-based asset handover. It covers the definition, the three core principles, the worksheet structure and the points where COBie differs from a full BIM model.

Definition

COBie (Construction Operations Building Information Exchange) is a non-proprietary data format for publishing and exchanging a subset of building information focused on assets rather than geometry. Its purpose is to standardize the handover of operational data from the construction team to the owner and facility management team.

Core principles

Principle Description
Classification system Data follows a pre-defined scheme such as OmniClass, UniFormat or MasterFormat, so naming and categorizing stay consistent.
Data model A relational model aligned with the buildingSMART Data Model (IFC). It links a pump to a room, the room to a floor, and the pump to a system.
Format A spreadsheet file (.xlsx), so the data is not locked into one software ecosystem.

Worksheet structure

A COBie workbook is split into tabs. Grouped by role:

  1. Context: Instruction, Contact, Facility.
  2. Spatial: Floor, Zone, Space.
  3. Assets: Type (product catalogue with manufacturer, model number and warranty data) and Component (one row per installed instance, with serial number, installation date and space).
  4. Relationships: System, Assembly, Connection.
  5. Maintenance: Spare, Resource, Job.
  6. Supporting data: Impact, Document, Attribute, Coordinate, Issue.

Type and Component have a parent-child relationship. A Type such as one air handling unit model can have many Component rows, one per unit installed.

COBie versus the full BIM model

Aspect Full BIM model COBie deliverable
Scope Geometry plus engineering data Asset data subset
Typical format Native authoring files Spreadsheet (.xlsx)
Main reader Design and construction teams Owner and facility team

COBie does not replace the model. It acts as a filter that specifies which data points facility management needs and gives them a schema.

Adoption milestones

  • 2007: first version published, initiated by the U.S. Army Corps of Engineers.
  • 2011: adopted into NBIMS-US Version 2 by the National Institute of Building Sciences.
  • April 2016: UK BIM Level 2 mandate fully in effect, requiring COBie for centrally procured public sector projects.

Practical checks

  • Confirm the BIM execution plan lists COBie requirements before modeling starts.
  • Confirm the source model carries asset attributes and classifications.
  • After handover, plan who updates the data in the CAFM or CMMS, because the delivered file is a snapshot of the as-built state.
