Scan to BIM in Washington DC: Technical Reference

This reference summarizes how a Scan-to-BIM engagement for a Washington DC building is specified, executed and delivered. It is written for coordinators who need the inputs, outputs and checkpoints in one place.

Definitions

Term Meaning in this context
Point cloud Registered laser scan data, preferred as RCP or RCS, with E57 accepted
LOD Level of Development, requested from LOD 100 up to LOD 500 depending on project needs
LOI Level of Information attached to modeled elements
Clash check Coordination test between architectural, structural and MEP elements
HPRB The DC Historic Preservation Review Board, which sets documentation requirements for designated landmarks

Disciplines modeled

Discipline Typical content
Architecture Walls, floors, ceilings, doors, windows, stairs, roofing, ornamental trim on historic buildings
Structure Steel, concrete and wood framing, foundations, columns, beams, bracing, connections
MEP HVAC ducts, conduits, panels, cable trays, plumbing, prepared for clash detection
Topography Terrain surfaces, grading, sidewalks, curbs, parking areas, visible utilities

Input checklist

  1. Point cloud data, registered, with individual files under 5GB.
  2. TrueView or site photos to confirm materials and finishes.
  3. Project scope: required LOD, disciplines, deliverable formats.
  4. Existing CAD or PDF drawings for hidden elements and historic grid lines.
  5. BIM standards, naming conventions and templates.
  6. Timeline and milestones.
  7. A named contact for technical questions and QC markups.

Execution sequence

  1. Brief analysis and scope clarification.
  2. Point cloud preparation and coordinate setup.
  3. Level and grid establishment.
  4. Element classification and modeling setup.
  5. Architecture modeling.
  6. Structure and MEP modeling when required.
  7. LOD and LOI validation.
  8. Family creation and parameter setup.
  9. Coordination and clash check.
  10. QA and QC review against the scan, tolerance typically within ±5mm.
  11. First model submission.
  12. Revision against client QC markups.
  13. Final delivery and closeout.

Deliverables

  • Revit models matching scanned site conditions.
  • LOD-based outputs from LOD 100 to 500.
  • 2D floor plans, sections and elevations generated from the model.
  • A model accuracy validation against the original scan.
  • Files in RVT, IFC, DWG and NWC formats.

Notes for DC projects

Federal buildings, historic landmarks and dense urban sites are the common drivers. Historic landmarks need documentation that meets HPRB expectations, so ornamental detail capture is part of the architecture scope. MEP models for mid-rise buildings with tight ceiling plenums are prepared so clash detection can run without rework. Projects without a point cloud can begin with a preliminary estimate from TrueView files, Google Maps links or site photographs, and quotes are given within 24 to 48 hours.
