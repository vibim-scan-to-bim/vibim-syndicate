Technical Reference: Project 701.UK Office Building Revit Modeling

This reference summarizes the specification, workflow and quality controls of Project 701.UK, a UK office building modeled in Revit.

Definitions used in the project

  • Federated model: the Architecture, Structure and MEP files linked together for coordination and clash detection.
  • Shared coordinates: one agreed position reference so separate files align.
  • TrueView: panoramic scan imagery used here for material review and visual checks.
  • Tolerance: the MEP model targeted ±15 mm against technical standards and equipment configuration.

Workflow steps

  1. Split the model into three files because of building size.
  2. Establish a unified coordinate system and assign object ownership to each file.
  3. Link all files into the federated model.
  4. Run recurring clash checks between architecture and structure in Revit and Navisworks.
  5. Verify wall materials with filters, schedules and TrueView.
  6. Estimate MEP effort by benchmarking against similar projects, since only PDFs and exterior photos existed.
  7. Model service shafts and line routes with dedicated staff; use parametric families for repeated objects.
  8. Review with sectional views, Navisworks checks and point cloud analysis tools before delivery.

Known constraints

Poor basement point cloud quality and dense rooftop plant rooms limited how much existing ventilation could be identified with confidence. The team handled this through targeted modeling and layered review.

Quality controls in detail

Review ran in layers. Sectional views let reviewers inspect ducts, pipes and equipment inside tight spaces. Navisworks checks looked for clashes between disciplines. Proprietary point cloud analysis tools compared the model with the scan. The team optimized these internal tools during the job, which raised inspection speed and efficiency. Because each MEP system holds thousands of objects, including ducts, pipes, fittings, equipment, cable trays, valves and sensors, the layered approach was the only practical way to control quantity and quality in a short QA-QC window.

Outputs

The deliverable is a Revit file set built to LOD300. The detailed models support design and construction and add long-term value for operation and maintenance, because location and specification data make management, repair and system upgrades easier across the building's lifecycle.
