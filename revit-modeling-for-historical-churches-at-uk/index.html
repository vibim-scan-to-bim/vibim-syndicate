Technical Reference: LOD 400 As-Built Revit Model of a UK Historic Church

This page records the specification, inputs, constraints, and modeling methods for a UK church project delivered by ViBIM. It is written as a reference, so each item can be looked up on its own.

Project specification

Item Value
Location United Kingdom
Building type Historic church (classical)
Modeled area About 2,000 m²
Floors 2
LOD, exterior, interior, topography LOD 400
LOD, facades LOD 300
Inputs Point cloud, TruView
Deliverable Revit file
Software Revit, Navisworks, TruView, internal tools

Scope

  • The entire church building.
  • The surrounding topography.
  • Selected facades of adjacent structures.

Definitions

LOD 400. A level of development where elements are modeled with the detail and accuracy needed for fabrication-level or highly precise documentation. Here it applies to the main building and the topography.

Point cloud. A set of measured points from laser scanning that records the surface geometry of an existing structure.

TruView. A viewer for scan data. The team used it to find locations and identify material types.

Model In-Place. A Revit tool for building a one-off element directly in the project when no loadable or system family fits.

Method

  1. Receive the registered point cloud and TruView data.
  2. Build a sample model for one small representative area.
  3. Submit the sample to the client to validate the modeling method.
  4. Model the exterior using layered walls: split a primary wall into walls of different thicknesses, attach thin material walls to a core wall, and apply the join tool.
  5. Model the interior and mark material transitions with model lines, using TruView to confirm location and material.
  6. Model curved ceilings and the vaulted dome with system families first. Use Model In-Place for components that system families cannot represent.
  7. Check alignment to the point cloud, structural composition, and category assignment for each element.
  8. Run phased internal quality control and cross-check with specialised software.

Known constraint

Revit has limits when walls are layered and joined. Join management needs close attention to keep the structure accurate.

Outcomes listed for the project

  • A millimeter-accurate as-built model.
  • Support for renovation and repair planning, including identifying repair zones and estimating material quantities.
  • A basis for heritage conservation, research, and digital archiving.
  • A model that can feed asset management systems.
