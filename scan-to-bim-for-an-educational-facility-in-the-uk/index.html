Technical Reference: Revit Model Specification for UK School Project 678.UK

This reference records the specification, inputs, constraints and modeling rules of Project 678.UK, a school in the United Kingdom modeled in Revit.

Project specification

Field Value
Project code 678.UK
Location United Kingdom
Industry Education
Client profile Confidential
Total area 4,900 m²
Number of floors 2
Structures 3 (one central main building, two arc-shaped wing buildings)
Level of detail LOD 400
Duration One month, August to September 2024
Inputs Point cloud, images, 2D drawings
Deliverable Revit file
Software Revit, Navisworks, internal tools

Disciplines in scope

  1. Architecture, interior and exterior elements.
  2. Structure.
  3. MEP (Mechanical, Electrical, Plumbing).

Definitions used in this project

  • LOD 400: a level of development at which elements are modeled with enough detail and information for fabrication and assembly. Here it applied to the architectural and structural components of the campus.
  • Revit category: the built-in classification that groups elements such as walls, floors and doors.
  • Family type: a defined variant within a Revit family that sets an element's parameters.
  • Material asset: a named material definition in Revit that is assigned to elements.
  • TrueView: panoramic imagery used alongside the point cloud to read surfaces.

Client requirements

  1. Name components accurately.
  2. Separate material types and create accurate material types inside the model.
  3. Classify each object under the correct category, with the correct family type and the exact material.

Priority rule

Systematic organization was ranked above the tightest geometric deviation (tolerance) against the point cloud. Where the two conflicted, the organization of categories, family types and materials took precedence, so the model keeps its informational value, interoperability and usability in later phases.

Procedure

  1. Read the shape of each surface from the point cloud.
  2. Cross-check finish and condition against high-resolution site photographs.
  3. Confirm the surface in context using TrueView imagery.
  4. Assign the material and verify naming.
  5. Build with Revit's native system families and categories wherever possible.
  6. Embed complete material information in any custom component.

Outputs and use

The model is a baseline for renovations, upgrades and maintenance planning. Material information, schedules and quantities can be extracted for any component, which feeds procurement, cost estimation and asset management.
