Technical Reference: LOD 400 Scan to BIM for a Four-Story Residence (Project 768.US)

This note records the specification and modeling methods used on Project 768.US, an as-built Revit model of a residential building in the United States.

Specification

Item Value
Project 768.US
Location United States
Industry Residential
Period May to June 2025
Total area 1,400 m² (about 15,070 sq ft)
Floors 4
LOD 400

Deliverable Revit file
Software Revit, Navisworks, internal tools
Services Architecture, structure and MEP scan to BIM; as-built BIM modeling

Definitions

  • Point cloud: a set of measured points from a laser scan that records visible surfaces only.
  • Occlusion: an area the scanner could not see, such as behind furniture.
  • LOD 400: a level of detail where elements match the real building closely enough to order replacement parts from the model.
  • Sweep: a Revit operation that moves a 2D profile along a path to form a 3D element.

Element-by-element method

Element Method
Cornices and wall moldings Cut a 2D section where the scan is cleanest, export as a polyline, sweep along the path
Door and window frames Cut a section of about 1-2 mm across the frame, then sweep and extrude
Handles, hinges, latches Separate LOD 400 families nested into the door family
Stair railings Set out from path, handrail profile, baluster size and spacing; alignment tools fix slope and gaps
Kitchen cabinets and similar units Many sections at several positions, tools combined
Lights, switches, outlets Typed from site photos, placed with ready LOD 400 MEP families

Verification steps

  1. Slice the model against the point cloud often while building.
  2. Run clash detection so small components do not sink into walls or floors.
  3. Check that each object holds its real size, shape and position.

Known constraints

The scan has occluded areas and noise. Decorative moldings near corners and noisy surfaces were the hardest to resolve, and exact depth of small fixtures was difficult to fix.

Intended use

Each object can store manufacturer, install date and warranty details, so the model supports repair planning, renovation and maintenance without re-scanning.
