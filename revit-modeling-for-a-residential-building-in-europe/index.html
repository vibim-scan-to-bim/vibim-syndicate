Technical Reference: Project 561.EU Residential As-Built Model

This page records the technical parameters and procedures of Project 561.EU, an as-built Revit model of an apartment building in the European Union. Work ran from October to November 2023.

Parameters

Item Value
Building type Residential apartment building
Location European Union
Gross area About 8,600 m² (92,570 sq ft)
Floors 6 (5 above ground, 1 basement)
Disciplines Architecture, structure, MEP
Level of detail LOD 300
Tolerance ±15 mm (±0.6 in)
Inputs Point cloud, PDF drawings
Deliverable Revit file
Software Revit, Navisworks, internal tools

Definitions

  • Registration: the process of aligning separate scans into one coordinate system. Poor registration between floors causes vertical elements to tilt.
  • Project North: the orientation of the model's plan view axes in Revit. Rotating it changes how every view reads.
  • Base point: the reference origin of the project coordinates. Moving it shifts how objects relate to the coordinate base.
  • LOD 300: a level of detail where elements are modeled with accurate size, shape, location and orientation.

Procedure: floor alignment

  1. Request the registration report from the scanning firm.
  2. Request re-registration where the reported error is large.
  3. Cut section views across the main axes.
  4. Align vertical elements through those sections rather than through the floor plan.
  5. Pick the floor with the best data and build one standard grid from it.
  6. Apply the grid to all six floors and adjust each floor's point cloud to it.

Procedure: rotation and base point change

  1. Split the model by discipline, because it cannot be rotated in one pass.
  2. Rotate each part, with MEP handled separately.
  3. Cross-check between floors and against the point cloud.
  4. Recheck every plan, elevation and section.
  5. Realign all MEP links.

MEP handling

Issue Response
Client families did not match the scan Redesigned from the originals to ±15 mm with client approval
Dense, varied lighting Modeled in place by one engineer, then placed using sections and 3D views
Inconsistent family parameters Internal tool rounds values automatically
Naming Classification table plus an auto-rename tool
Vertical and wall-mounted cable trays Custom family
Long runs across many rooms Techniques from earlier projects to avoid missed segments

Quality control

The model was divided into smaller parts and checked room by room, moving sections through each room. Modelers compared the model with Matterport views during production.

Result

A coordinated as-built model that agrees with the 2D drawings, follows the project's BIM standard and is suitable for renovation, repairs and asset management.
