Revit Point Cloud Selection Reference: Settings, Causes and Steps

This reference covers one narrow problem: a point cloud linked into a Revit project that does not respond to a mouse click. The point cloud files in question are RCP and RCS data. The behavior looks like a frozen model, but it is a property of the selection settings and not a sign of damaged data.

Definitions

Term Meaning in this context
Selection Control The set of filters Revit uses to decide which element types accept a click. When a filter is off, the viewport ignores the cursor for that type.
Select Links The toggle that allows clicking linked data, including a linked point cloud.
Select Pinned Elements The toggle that allows clicking elements that have been pinned in place.
RCP / RCS Point cloud file formats that Revit can reference as background survey data.

Why Revit blocks the click

Revit disables selection of linked references on purpose. The restriction protects referenced survey data from accidental movement, because a stray drag on a point cloud could shift its coordinates relative to the model. So a point cloud that "cannot be selected" is usually protected, not broken.

Fix, step by step

  1. Open the Modify tab on the main ribbon.
  2. Find the Select drop-down menu at the far left of the panel.
  3. Turn on Select Links.
  4. Turn on Select Pinned Elements.
  5. Click the point cloud in the viewport to confirm it now responds.

A faster route exists. The Status Bar at the bottom right of the window carries a chain-link icon. That icon opens the same filters, so you can change them without going back to the ribbon.

What to check before assuming a selection problem

Confirm the point cloud file formats you linked are ones Revit supports. Treat the selection settings as the cause only after the file format is ruled out.

Selection is not modelling

Being able to click a scan does not produce a model. Converting point cloud data into Revit elements is a separate workflow with its own accuracy targets. When the scan data has to support an as-built deliverable, a Scan to BIM service provider can validate the imported survey data and build the Revit model to the required scope.

Quick checklist

  • Point cloud does not respond to clicks: check Select Links first.
  • Pinned items also ignore clicks: check Select Pinned Elements.
  • Toggles are quicker from the Status Bar chain-link icon.
  • File format unsupported: fix that before touching selection settings.
  • The restriction is a safeguard that keeps referenced coordinates stable, so switch it on only when you need to select the data and consider switching it off afterwards.

Keeping these toggles in mind saves time on any project that links scan data, because the same two settings explain most cases where a viewport appears unresponsive to a click on referenced content.
