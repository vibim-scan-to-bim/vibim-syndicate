Project 556.UK: Technical Reference for a Multi-Volume As-Built BIM

This page records the technical parameters of Project 556.UK, an as-built BIM model of a landmark office tower complex in central London, delivered between September and December 2023.

Specification

Parameter Value
Location United Kingdom (central London)
Industry Commercial and office
Total area 18,000 m² (193,750 sq ft)
Floors 24
LOD, architecture LOD 300
LOD, topography LOD 400
LOD, MEP LOD 200
Inputs Point cloud, TruView
Deliverable Revit files
Software Revit, Navisworks, internal tools
Tolerance ±15 mm (±0.6 in) against the source scan
Model split 7 linked Revit volumes

Definitions

  • As-built BIM: a model of a building as it exists, built from survey data rather than design drawings.
  • LOD (level of development): how much detail and reliability model elements carry. Here it varies by discipline.
  • Point cloud: a set of 3D points captured by laser scanning.
  • TruView: a browser view of scan data used alongside the point cloud.
  • Linked volume: a separate Revit model referenced by others so a large building can be split into manageable parts.

Composition of the estate

  1. Podium: about 9,000 m², one basement and two upper levels.
  2. Main tower: 19 floors, about 2,080 m² per floor.
  3. Secondary tower: five floors, about 1,150 m² per floor.
  4. Surrounding topography.

Scope of services

Architecture, structural, topography and MEP scan to BIM, under as-built BIM modeling.

Workflow

  1. Internal kickoff to fix scope and quality targets.
  2. Assign one coordinator per volume.
  3. Model key podium exterior and interior objects first.
  4. Match topography to those objects and run a clash check.
  5. Build external and interior models in parallel, shared elements such as walls first.
  6. Manage the point cloud by region, showing only the scan data in hand, often unlinked from the model.

Known constraints

Heavy scan data slows files and raises crash risk. Alignment of topography, podium exterior and podium interior is the critical coordination point, since pavements must meet external walls and basement objects.

Result

A coordinated existing-asset record usable for renovation, spatial planning and cross-disciplinary coordination.
