Technical Reference: Structural As-Built Model of a Non-Linear Roller Coaster (Project 605.Canada)

This page documents the technical parameters and method of a structural Scan to BIM project completed for a roller coaster in Canada.

Project parameters

Parameter Value
Project code 605.Canada
Duration Two months, February to March 2024
Sector Recreation / Entertainment
Client profile Confidential reality capture specialist
Total area 2,300 m²
Number of floors 1
Level of detail LOD 300
Input Point cloud
Deliverable Revit file
Software Revit, Navisworks, internal tools
Discipline Structure only

Definitions

  • As-built model: a model that represents the structure as it exists, based on measured data rather than design intent.
  • LOD 300: a level of detail at which elements are modeled as specific, correctly defined components with accurate size, shape and position.
  • Massing: Revit forms used here as placeholders to fix node geometry.
  • Pick Path: a Revit method that makes a structural element follow a pre-defined path.

Requirements

  1. Build a high-fidelity 3D structural model from the point cloud, usable as a reference for re-engineering and analysis in other platforms.
  2. Represent beams, columns and connections accurately, matching the real construction.
  3. Model the full track length, support columns and lateral bracing.

Procedure

  1. Identify the intersection nodes between track segments and supports in the point cloud.
  2. Create Massing forms at each node to lock coordinates.
  3. Connect the nodes into a complete 3D path that acts as the centerline.
  4. Load custom structural framing families built to match the track profile.
  5. Apply Pick Path so each family instance conforms to the path.
  6. Check the result against the point cloud and keep structural parameters attached to each element.

Constraints

Standard beam and column placement was impractical because the track has continuous, non-uniform curves in both horizontal and vertical directions. A surface model was rejected because an element-based BIM model was required.

Intended use

Asset management, structural integrity analysis, renovation planning and maintenance.
