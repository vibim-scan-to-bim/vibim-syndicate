Project 330.CAN: Technical Reference for a Canadian Train Station Revit Model

This page records the technical parameters, constraints and workflow of a Scan to BIM project for a railway station in Canada.

Project parameters

Parameter Value
Project code 330.CAN
Asset type Train station
Location Canada
Total area 6,700 m²
Floors 2
Disciplines Architecture, structure, topography
Level of detail LOD 200
Input Point cloud (sole input)
Deliverable Revit file
Software Revit, Navis, internal tools
Team 7 specialists
Duration Two months, January to February 2022

Definitions

  • Point cloud: a set of measured points from laser scanning that records the surfaces of an existing structure.
  • LOD 200: a level of detail at which elements are modeled with approximate size, shape and position.
  • Top rail alignment tolerance: the permitted deviation of the upper rail surface from its true position. Here the limit was 10 mm.

Site and geometry constraints

  1. The site is terraced.
  2. The station extends from street level to lower levels.
  3. Train tracks run at a middle level.
  4. Multiple internal floors and many structural elements share the volume.
  5. The bridge beam system has sloped, irregular cross-sections along the track length.
  6. The roofs include numerous slanted and arched glass forms.

Workflow

  1. Receive the client point cloud.
  2. Cross-reference the scan with Google Maps imagery and related documentation to understand the structural framework.
  3. Model architecture, structure and topography in Revit to LOD 200.
  4. Model the railway track and analyze it in specialized software.
  5. Monitor deviations continuously and apply corrections.
  6. Confirm the rail stays within the 10 mm tolerance.
  7. Run clash checks and deliver the Revit file.

Intended uses of the model

  • Renovation design
  • Space reconfiguration
  • System upgrades
  • Possible expansion
  • Asset management and information integration within the urban infrastructure system

Review result

The client reported that the model looked excellent at a high level, that comments were minor, and that overall quality was great.

Notes

The station name appears with different wording in the source page, so this reference uses the project code and the term train station.
