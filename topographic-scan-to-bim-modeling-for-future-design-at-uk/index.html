Project 380.UK: Technical Summary of a Topographic Scan-to-BIM Model

This page records the specification, method and verification steps for Project 380.UK, a topographic Revit model of a single-level UK site.

Specification

Item Value
Project 380.UK

Deliverable Revit file

Duration One month, June to July 2022
Deviation tolerance ±25 mm from the point cloud

Definitions used

  • LOD 400: elements are modeled with accurate assembly information, and that detail must match real-world conditions captured in the scan.
  • Deviation analysis: a direct comparison between the BIM model and the source point cloud, used to confirm each element stays within tolerance.
  • As-built model: a model of existing conditions rather than proposed design.

Scope

The model covers the entire site terrain, including roads, sidewalks and landscape-related structures. The purpose is to provide a reliable information base for future design and development, plus archival 2D documentation produced from the 3D model.

Constraints

  1. The LOD 400 requirement demands accurate assembly information that still agrees with the point cloud.
  2. Terrain and the transport network must form one continuous, seamless surface across a large area.
  3. Many unique site objects require custom Revit families, which can become a schedule bottleneck.
  4. Surface types need clearly separated materials to support quantity takeoffs and asset management.

Method

  1. Segment the site into smaller topographic sections.
  2. Model each section independently to keep performance and precision.
  3. Join the sections into one complete as-built model.
  4. Batch-load custom families with a proprietary in-house tool.
  5. Identify materials by cross-checking client site photographs against satellite data such as Google Maps.

Verification

  1. Run a deviation analysis between the model and the point cloud with specialized internal software.
  2. Inspect structure and composition with detailed Revit section views and component inspection software.
  3. Confirm every element sits within the ±25 mm tolerance.

Services covered

Topography Scan to BIM, MEP Scan to BIM, As-Built BIM Modeling, Scan to Revit Family Creation, Scan to 2D As-Built Drawings, Scan to BIM for Facility Management.

Result

A definitive 3D as-built model that replaces error-prone manual surveys and serves as the single source of truth for later work on the site.
