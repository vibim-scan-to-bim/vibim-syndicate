Technical Reference: Project 311.CAN Hospital Complex Revit Model

This reference summarizes the specification, workflow and quality controls used for a hospital complex modeled in Revit from survey data. All values come from the project record.

Definitions

  • LOD 300: the level of development at which elements are modeled with defined geometry, size and position, as applied here to every discipline.
  • Record Model: the reference model compared with as-built conditions to support asset maintenance and preservation.
  • Trueview: Leica viewing format used here for annotated, photo-linked scan review.
  • Clash detection: automated checking in Navisworks to find conflicts between systems.

Scope note

This was a partial modeling project. Architectural base elements were included, with the main focus on MEP systems for management, renovation and operation of technical infrastructure.

Workflow

  1. Estimate effort from the limited MEP inputs (PDF documents and exterior photographs).
  2. Segment the model by zone.
  3. Generate sections and elevations per area to read dense object clusters.
  4. Classify each system correctly before modeling (HVAC, fire protection, potable and waste water, conduits, cable trays, medical gas, suction and pressure).
  5. Label ventilation system types using as-built photographs combined with Trueview annotations.
  6. Build plumbing routes strictly from the supplied 2D drawings.
  7. Create specialized duct fittings for bends and transitions where the scan demands it.
  8. Run Navisworks clash detection.
  9. Complete QA-QC with several inspection layers.
  10. Confirm that every issue found in QC is resolved before handover.

Known risk areas

  • Overlap of services in technical shafts, equipment rooms, basements and corridor ceilings.
  • Misclassification, for example a conduit modeled as a pipe or duct.
  • Heavy point cloud coverage of the exposed ceiling, which slows modeling of critical ventilation.
  • Short QA-QC timeframes relative to the number of MEP objects.

Result

A labeled model of existing MEP conditions that reduces field surveys and serves as a data foundation for maintenance, repair, upgrade and facility management stages.
