Technical Reference: Museum Existing-Conditions Model (Australia, LOD 300)

This reference summarizes the specification, inputs and method of an existing-conditions Revit model for an Australian museum site.

Project specification

Field Value
Client profile 303.AUS, described as the largest museum group in Australia
Location Australia
Industry Museum
Total area 22,000 m²
Number of floors 2 basements, 5 floors
Level of development LOD 300
Inputs Point cloud, TrueView
Deliverable Revit file
Software Revit, Navisworks, TrueView, internal tools

Definitions

  • Point cloud: a set of measured 3D points captured by scanning, used as the geometric reference for modeling.
  • TrueView: a viewer for scan data, used here to inspect scans and check dimensions.
  • LOD 300: a level of development in which elements are modeled with defined geometry and are accurate enough for coordinated documentation.
  • Family: a reusable Revit component. Here, families were built for museum-specific elements.

Scope of modeling

  • Architectural and structural elements, including columns, beams and frames
  • Internal and external conditions of the two museum buildings
  • Outdoor features: plazas, pedestrian bridges, shade structures

Constraints

  1. Large site area with significant level differences between zones.
  2. Complex details: domes, railings, decorative columns, glass doors, intricate façades.
  3. Multiple modelers within one project, which raises coordination and quality-control demands.

Method

  1. Segment the project into zones by elevation, architectural features and complexity.
  2. Prioritize modeling order by schedule and complexity.
  3. Verify accuracy with several Revit sections, Navisworks and TrueView where elevations differ.
  4. Create a family library for repeating museum elements.
  5. Define roles, responsibilities, quality-control steps and communication procedures.
  6. Review and validate models regularly to detect and correct errors.

Downstream use

The model gives a precise, visual information source for operation, maintenance, repair and upgrade stages. It was exported to Lumion, Twinmotion and Enscape for perspective renderings and fly-through videos used in marketing, education or fundraising and restoration work.

Checklist for similar projects

  • Confirm the LOD and deliverable before modeling starts.
  • Zone the site before assigning people.
  • Build custom families early.
  • Validate against the scan at each elevation change.
