Point Cloud to Revit: Technical Reference

This page is a compact reference for converting a laser-scan point cloud into a parametric Revit model. It lists formats, settings, the modeling sequence and the validation steps in the order a team uses them.

Definition

Point cloud to Revit modeling is the reconstruction of an existing building from scanned points into parametric Revit elements. A point cloud in Revit is a linked set of millions of points. It is purely geometric. The conversion adds type, dimension, material and phase data through Revit families.

Supported formats

Format Origin Links directly in Revit Action
RCP / RCS Autodesk ReCap output Yes Link as delivered; an RCP file points to several RCS scans
E57 Open standard (ASTM E2807) No Index in ReCap Pro to RCP or RCS first
PTS, PTX, LAS, FLS, ZFS Scanner-native or legacy No Convert via ReCap Pro first

Transfer rule of thumb from the source guide: keep each RCS file under 5 GB, or zip the dataset into one archive per transfer.

Positioning methods

Method Use it for
Auto - Origin to Origin Default for scans on a local coordinate system
Auto - Center to Center Quick look only; no coordinate accuracy
Auto - By Shared Coordinates Georeferenced data with survey control points
Auto - Origin to Last Placed Stacking several files from one site, available from the second scan

Procedure

  1. Confirm the scan is registered, cleaned and saved as RCP or RCS.
  2. Insert tab, Link panel, Point Cloud. Pick the file and a positioning method.
  3. Verify position and scale in a 3D view by measuring one known dimension.
  4. Create levels by snapping to floor and ceiling surfaces, then place grids on the column lines the scan shows.
  5. Trace architecture, then structure, then MEP, using plan and section views.
  6. Use Model In-Place or massing only for leaning or curved elements. Overuse makes the file heavier.
  7. Validate against the source scan before delivery.

Display controls

Open Visibility/Graphics (VG), Point Clouds category. Available color modes are True Color (RGB), Elevation, Intensity and Normals. Point size can be set per view. Use a section box in 3D, and the crop region plus View Range in plan and section views.

Validation

  • Section checks in Revit: paired cuts through model and cloud, measured with Measure Between References.
  • Deviation and clash checks in Navisworks: catches small objects such as valves, minor equipment and lighting.
  • File health: consistent naming, correct levels, worksets and phases, resolved warnings, purged unused content.

Tolerance follows the project specification and the scan quality. It is not one fixed figure.

Performance tactics

Limit the points drawn at once. Use section boxes, lower point density per view, work in plan and section, close unused views, and keep the cloud on its own workset. For extremely large datasets, decimate through ReCap, or split the data per level or zone.

Automation status

No production-ready tool converts a point cloud into a deliverable Revit model automatically. Mesh converters output mesh or NWC with no parameters or families. AI-assisted tools give partial detection that still needs manual verification. Manual tracing over a linked cloud remains the production standard.
