Revit Software: Technical Reference for Existing-Building Projects

This reference summarises the parts of Revit that matter most when a model is built from survey data of a building that already stands.

Definition

Revit is Autodesk's Building Information Modeling (BIM) authoring software for the architecture, engineering, and construction industry. A project is a single database of parametric objects. A wall is placed as an object that carries its own height, material, and room relationships, and edits propagate to every plan, section, and schedule that references it. The name is a contraction of "Revise-Instantly". The software began at Charles River Software, founded in 1997, and Autodesk acquired the company in 2002.

Object hierarchy

Level Meaning
Category The broad kind of element, such as Doors or Walls
Family A specific model within a category
Type A size or variant of a family
Instance One element placed in the building

Classifying an element at the wrong level lets the error travel downstream, where schedules count the wrong thing.

File formats

Extension Purpose
.rvt Complete project model: geometry, data, views, schedules, sheets
.rfa Single loadable component, built in the Family Editor
.rte Project template with units, standards, views, and preloaded families
.rft Family template with reference planes and parameters
IFC Open exchange format; specify IFC2x3 or IFC4 for the receiving team
DWG 2D sheets for CAD users
RCP / RCS Point cloud input

An IFC file keeps geometry and attributes, while the parametric behaviour lives only in the .rvt. If the model must still be edited downstream, deliver .rvt. If it only needs to be read, IFC may do.

Procedure for an existing building

  1. Inspect the point cloud for duplicated points, misaligned setups, and unscanned areas.
  2. Agree the Revit version, units, and coordinate system, or use the client template.
  3. Link the cloud with origin-to-origin or shared coordinates, as the client decides.
  4. Create starting views: usually two vertical sections, one horizontal section, and a 3D view.
  5. Model the dense main runs first, then the sparser secondary areas.
  6. Run a section check and a Navisworks check, then a final pass over naming, levels, worksets, warnings, and phases.

Practical constraints

  • Keep each RCS file at or below 5 GB, or send one zipped dataset per transfer.
  • Autodesk recommends a multi-core processor at 3.0 GHz or faster, 32 GB to 64 GB of RAM, and a dedicated graphics card with 8 GB or more supporting DirectX 12.
  • Revit is sold by subscription, monthly or annual, or inside the Autodesk AEC Collection. There is no one-time purchase.
  • A mobile scanner limits the achievable level of development. LOD 300 on every element generally needs a terrestrial scan.

Typical turnaround

Project size (hours) Business days
100 to 200 4 to 7
200 to 300 7 to 8
300 to 500 8 to 12

The accuracy of the model is capped by the survey behind it, so the data and the modeling skill decide the result, not the licence.
