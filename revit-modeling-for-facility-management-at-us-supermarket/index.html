Technical Reference: Butterfly Valve Revit Family for Facility Management (LOD 400)

This page records the specification and build method of a Revit family delivered in a ViBIM sub-project for a US supermarket. It is written as a reference for BIM modelers who need data-rich MEP components for facility management.

Project specification

Definitions

  • Revit family: a parametric component that carries geometry and data.
  • Nested family: a family placed inside a host family to control parts separately.
  • Lookup table: a table that returns dimensions and data from an input value such as nominal diameter.
  • MEP connector: the connection point that links a component to a piping system.
  • Type vs. instance parameter: a type parameter is shared by all elements of a type; an instance parameter changes per placed element.

Requirements

  1. Comply with industry standards (flange dimensions, clearance requirements, installation spacing) and the project BIM Execution Plan.
  2. Embed dimensions, material information, pressure ratings, flow rates, manufacturer data and product codes.
  3. Stay lightweight so the main project file keeps its performance.

Build procedure

  1. Scope geometry, parameters, connection points and use case.
  2. Create reference planes and constraints to drive core dimensions.
  3. Model handle, body and flange as separate families and nest them in one host.
  4. Group parameters: Dimensions, Technical Data, Materials, Visibility.
  5. Apply void forms only where needed and add visibility parameters for secondary parts such as the handle, hidden at Coarse and Medium.
  6. Add lookup tables for standard sizes.
  7. Configure MEP connectors with system classification, flow direction and pressure.
  8. Test in a sample project: resizing, pipe connection, level-of-detail display, parameter output.
  9. Write documentation covering intended use, key parameters and limitations.

Known difficulties

Moving parts need accurate geometry. Parameter sets can grow hard to manage. LOD 400 detail competes with file size. Connectors must be exact for analysis to work.

Outcome

The family supports model reliability, coordination between disciplines, performance analysis, and facility management tasks such as asset tracking and preventative maintenance scheduling.
