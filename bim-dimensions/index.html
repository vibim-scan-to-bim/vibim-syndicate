BIM Dimensions: Technical Reference From 2D to 10D

This page is a compact reference for the data layers, called dimensions, that can be attached to a building information model. Each entry gives the definition, the data added and the usual benefit.

Definition

A BIM dimension is a category of information, such as time, cost or energy, attached to one coordinated 3D model instead of kept in separate documents. Because every layer sits on the same model, a change in one place is reflected everywhere at once.

Reference table

Dimension Name Data added Usual benefit
2D Documentation Flat X and Y drawings, plans, sections Baseline documentation
3D Geometry Information-rich model on x, y, z axes Visualization, clash detection, coordination
4D Time Construction schedule linked to elements Sequencing, phasing, fewer delays
5D Cost Cost data and quantity takeoffs Real-time budget control
6D Sustainability Energy and lifecycle-performance data Energy efficiency, green compliance
7D Facility management Asset, warranty and maintenance data Efficient operation after handover
8D Safety Hazard, risk and safe-sequence data Fewer on-site incidents
9D Lean construction Workflow and resource-optimization data Less waste, higher productivity
10D Industrialization Prefabrication, modular and off-site data Faster, standardized delivery

Key relationships

  • 4D equals 3D plus time.
  • 5D equals 4D plus cost.
  • 3D, 4D and 5D are agreed worldwide; 6D and above vary by source.
  • 5D quantity takeoffs assume elements developed to LOD 300 or above.

Dimensions, LOD and maturity levels

These are three independent measures of the same project.

  1. Dimensions classify the type of data in the model.
  2. Level of Development (LOD) classifies how detailed and reliable that data is.
  3. BIM maturity levels (0 to 3) classify how collaboratively data is shared.

A single project can sit at maturity level 2, hold LOD 350 elements and use several dimensions at once. A 5D estimate at LOD 100 is a rough area-based figure, while at LOD 300 it is built from specific, manufacturer-defined components.

Why numbers above 5D are ambiguous

No single international body has standardized the higher dimensions. The National Building Specification (NBS) notes that consensus is limited past 5D, and buildingSMART favors plain-language use cases such as sustainability analysis or facility management data. Some sources reserve 10D for the digital twin instead of industrialization.

Practical steps

  1. List the decisions the model must support.
  2. Choose only the dimensions that answer those decisions.
  3. Write the required data, its timing and its format into the project standards, not just a dimension number.
  4. Confirm the underlying 3D geometry is accurate, since every layer depends on it.
