Project 314.UK: Technical Reference for an LOD 300 As-Built Revit Model

This reference summarizes the specification, constraints and method of Project 314.UK, an as-built BIM model of a commercial building in the United Kingdom.

Specification

Item Value
Client profile Confidential
Location United Kingdom
Industry Commercial building
Total area 6,250 m² (67,270 sq ft)
Number of floors 8
Level of development LOD 300
Input Point cloud
Deliverable Revit file
Software Revit, Navisworks, internal tools
Geometric tolerance ±15 mm (±0.6 in)
Period December 2021 to January 2022

Definitions

  • As-built model: a BIM model that records the building as it exists, not as originally drawn.
  • LOD 300: a level of development where elements are modeled with defined geometry, size, shape and location.
  • Point cloud: a large set of measured 3D points captured by scanning, used as the reference for modeling.
  • Non-geometric data: information attached to an element, such as material, capacity and technical specification.
  • Deviation analysis: a check that compares a modeled element with the point cloud.

Constraints

  1. A curved roof that does not follow standard parametric shapes.
  2. Slanted, non-perpendicular walls that prevent reuse of floors.
  3. Dense HVAC ductwork in large technical rooms, branching through the lower ground and basement.
  4. Small-diameter sprinkler pipes that appear blurred in the point cloud.
  5. Scattered electrical panels and cable trays.
  6. Every family matched to its real object in material, size, weight and capacity.

Method

Roof

  1. Read key horizontal and vertical sections from the point cloud.
  2. Extract 3D reference curves from those sections.
  3. Build a mass and a surface that match the scan.
  4. Apply thickness and material with Revit's Roof by Face function.
  5. Run deviation analysis against the point cloud.

Walls and floors

  1. Measure each wall's real angle against the main grid.
  2. Model each level from point cloud data cropped to that level.
  3. Check junctions with the floors above and below, especially columns and cores.
  4. Use a live 3D view with the point cloud as background and a 3D section box for complex areas.

MEP

  1. One engineer owns HVAC from the main plant rooms along the technical risers.
  2. One specialist handles fire protection.
  3. One member sweeps ceiling-mounted equipment using 2D sections and the 3D model.
  4. Plumbing, panels and cable trays are divided into bounded zones, each with one modeler.

Quality control

Cross-check the Revit model, Navisworks and detailed sections in parallel while modeling.

Result

A single model covering architecture, structure and MEP, suited to renovation design, spatial planning and facility management.
