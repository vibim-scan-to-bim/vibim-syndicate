Technical Reference: As-Built BIM for a Three-Floor Retail Supermarket (Project 385.UK)

This page records the technical parameters, method and verification steps of ViBIM's Project 385.UK, an as-built Revit model of a UK supermarket completed between June and September 2022.

Specification

Parameter Value
Location United Kingdom
Industry Supermarket / Retail
Total area 7,380 m² (79,440 sq ft)
Floors 3
Level of development LOD 300
Inputs Point cloud, 2D drawings
Deliverable Revit file
Software Revit, Navisworks, internal tools
Accuracy target within ±15 mm (±0.6 in) of the point cloud
Client Confidential

Scope of work

  • Architecture Scan to BIM
  • Structural Scan to BIM
  • MEP Scan to BIM
  • As-built BIM modeling

Definitions

  • Point cloud: a large set of measured 3D points captured on site, used as the geometric reference for the model.
  • LOD 300: a level of development in which elements are modeled with accurate size, shape, location and orientation.
  • Clash detection: automated comparison of disciplines to find elements that occupy the same space.
  • As-built model: a model that records existing conditions rather than design intent.

MEP and equipment coverage

The model includes electrical, lighting, HVAC, plumbing and fire protection systems with fittings and connections. It also includes retail equipment: counters, refrigerators, checkouts, display boards and specialist lighting.

Procedure

  1. Classify services into groups: HVAC, fire protection, electrical and supermarket equipment.
  2. Assign named staff to each group.
  3. Model architecture, structure and MEP from the point cloud and 2D drawings.
  4. Compare the Revit model with the point cloud on a regular cycle, using Navisworks and in-house tools, to hold the ±15 mm tolerance.
  5. Run clash detection between architecture, structure and MEP, and resolve conflicts before the renovation design stage.
  6. Assign materials from site photographs and point cloud color data, including the external paint finish.

Known constraints

  • The basement and shop floor held equipment at high density, so mechanical and electrical clashes concentrated at the ceiling and service floor.
  • The client required the external walls to match the real building in color and material.

Outcomes

The model reflects real store conditions. It reduces errors in renovation design and construction, supports faster decisions across design, build and ownership teams, and provides a base for analysing space use, customer flow and fixture layout.
