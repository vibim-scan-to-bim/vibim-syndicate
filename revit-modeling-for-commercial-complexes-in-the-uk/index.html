Technical Reference: 310.UK Commercial Complex Scan-to-BIM Workflow

This reference documents the parameters, risks and countermeasures of a large-scale as-built Revit modeling job for a multi-building commercial complex in the United Kingdom.

Project parameters

Parameter Value
Location United Kingdom
Sector Commercial complex
Modeled area About 130,000 m²
LOD LOD 300, architecture and structure
Inputs Point cloud, 2D CAD
Deliverable Revit files
Software Revit, Navisworks, internal tools
BIM standard BIM Level 2

Scope definitions

  • Main structure: the central commercial centre, modeled in architecture and structure.
  • Adjacent buildings: several neighbouring buildings, modeled as 3D façades with 360-degree coverage.
  • Topography: detailed ground modeling around the main structure.
  • Drawings: produced to the client's own standards.

Risk and countermeasure matrix

Risk Effect Countermeasure
Very high point cloud volume Slow loading, crashes, RAM overload Segment the dataset before conversion; filter redundant points in Recap
Multiple modelers Synchronisation and quality control errors Zone ownership; standard documentation
Scan delivery in batches Gaps between scanning phases Zone-level tracking of each batch
Very large area Incomplete review of objects Per-zone review by the zone owner
Large site scale Large objects, slow modeling Internal tools and scripting
Late method change Rework on very large surfaces Dynamo script

Procedure for the late pathway change

  1. Receive the client request to model paved pathways as Floors instead of Topography. Roughly one quarter of the delivery time remained.
  2. Generate the Topography object with an internal tool.
  3. Run a Dynamo script that converts the Topography mesh into Floor elements.
  4. Align each Floor to the original topography surface.
  5. Review the result by zone.

The script reduced manual modeling time by 90%.

Infrastructure note

The project required high-specification workstations and server infrastructure to support concurrent multi-user work with stable performance.

Outcomes

The as-built model supports assessment of spatial relationships, technical infrastructure and traffic connectivity. It is a base for renovation design, spatial reconfiguration and installation of additional systems. Visualizations of daytime and nighttime scenes were also produced, with material coordination, lighting and landscaping.
