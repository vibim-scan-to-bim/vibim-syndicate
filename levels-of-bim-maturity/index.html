BIM Maturity Levels 0 to 3: A Technical Reference

This reference sets out the four BIM maturity levels as a set of definitions, data rules and checks. Use it when a scope of work, a tender or a project brief names a maturity level and the team needs to know what that level asks for in practice.

Definition

A BIM maturity level is a milestone that measures how far a project, an organization or an industry has moved in BIM adoption. The measure looks at the degree of collaboration and information sharing between project stakeholders. The scale is often drawn as the Bew-Richards triangle or wedge, a model that began in the UK and has influenced global standards.

Three attributes that define maturity

Attribute What it describes
Collaboration Connectivity and data exchange between project teams, from none at Level 0 to real-time at Level 3
BIM data management How models are used to create, visualize and manage digital information about the building across its lifecycle
Lifecycle integration How far BIM data connects design, construction, operation and maintenance

Level-by-level reference

Level Name Data format Key rule
0 No collaboration 2D CAD, paper or electronic prints Each discipline works in isolation, no shared data
1 Partial collaboration Mixed 2D and 3D A Common Data Environment (CDE) is required, CAD standards follow BS 1192:2007
2 Full collaboration Separate 3D models per discipline, combined into a federated model Information exchange uses open formats such as IFC and COBie
3 Full integration One shared, cloud-based project model Open data and Open BIM principles, real-time updates

Notes on each level

  1. Level 0 is now treated as obsolete practice. The lack of integration raises the chance of errors and rework.
  2. Level 1 is sometimes called "lonely BIM". The CDE exists, but models are not usually distributed for collaborative development.
  3. Level 2 allows clash detection and design review inside the federated model. 4D (time) and 5D (cost) BIM become fully feasible here. The UK government required Level 2 for centrally procured public projects by April 2016, after a 2011 strategy set the target.
  4. Level 3 replaces federated models with one model. It also supports 6D (sustainability) and 7D (facility management) uses.

Maturity, dimensions and LOD are different things

  • Maturity level: how mature the collaboration and data exchange are.
  • BIM dimension: the type of data added to the model, such as time or cost.
  • Level of development (LOD): the detail and reliability of model elements at a given stage, for example LOD 300 or LOD 350.

A contract that asks for Level 2 maturity when the project really needs a set LOD changes both the deliverable and the price. Check which of the three the document means before you quote or model.

ISO 19650

The ISO 19650 series formalizes the principles of UK Level 2 as a global standard. It covers information management over the full life cycle of a built asset.

Pre-start checklist

  • Confirm which maturity level the client expects.
  • Confirm that a CDE is in place for Level 1 and above.
  • Confirm the exchange formats, for example IFC and COBie at Level 2.
  • Confirm the LOD separately from the maturity level.
  • Check that the incoming models are consistent, because collaboration breaks down when the underlying data is not.
