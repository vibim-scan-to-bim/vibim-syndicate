Technical Reference: MEP-Only Revit Model of a US Industrial Building (Project 486.US)

This note records the technical parameters and workflow of an MEP-only modeling project for an industrial facility in the United States.

Project parameters

Item Value
Project code 486.US
Location United States
Building type Industrial building
Total area 3,800 m²
Levels 1 ground, 5 upper floors
Level of development LOD 300
Inputs Point cloud, PDF, images
Deliverable Revit file
Software Revit, Navisworks, internal tools
Dimensional tolerance ±15 mm

Definitions

  • MEP-only scope: only mechanical, piping, ductwork, electrical and plumbing objects are modeled. Architectural and structural elements are excluded.
  • LOD 300: model elements with defined size, shape, location and orientation, suitable for coordination and maintenance use.
  • Show Disconnect: a Revit tool that flags open connectors in piping and duct networks.

Workflow

  1. Estimate effort by benchmarking against similar projects and the traits of this plant.
  2. Split the model by floor and area.
  3. Model main pipes and risers, then secondary branches.
  4. Build complex machinery as subassemblies and assemble them in Revit.
  5. Identify pipe systems from the point cloud, endpoints and equipment connections.
  6. Assign material colors and filters per system.
  7. Test connectivity with Show Disconnect.
  8. Detect clashes in Navisworks and resolve them.
  9. Correct all QC findings before handover.

Known constraints

  • Input data was limited for MEP disciplines, with PDFs and exterior images only for interior context.
  • Point cloud quality was limited in dense areas.
  • Cable trays crossed shafts, electrical rooms and machine areas.

Output use

The model supports maintenance, asset management, renovation and future design work on the plant.

Verification checklist

  • [ ] All six levels modeled for mechanical, piping, ductwork, electrical and plumbing objects
  • [ ] Each pipe system carries its own material color and filter
  • [ ] No open connectors reported by Show Disconnect
  • [ ] Navisworks clash report reviewed and conflicts resolved
  • [ ] Dimensional tolerance of ±15 mm confirmed against the available reference data
  • [ ] QC findings corrected and the model reflects the as-built state

Modeling priorities

Main pipes and risers carry the most dependencies, so they come first. Secondary branches follow once the main routes are stable. Machinery with complex geometry, such as conveyors and production equipment, is split into subassemblies so each part can be checked on its own before assembly.

Estimating note

With only PDFs and exterior images for MEP context, interior density and the number of technical shafts could not be measured directly. The estimate relied on benchmarking against similar projects and on the characteristics of this plant.
