Project 758.US: Technical Reference for a Factory Revit Model

Summary

Project 758.US is an as-built Revit modeling job for an industrial factory in the United States. This page records the technical parameters, the problems met and the controls applied.

Definitions

  • As-built model: a model that records existing conditions of a facility rather than a design proposal.
  • MEP: mechanical, electrical and plumbing systems.
  • LOD 400: a level of development suited to detailed modeling used for fabrication and assembly.
  • Point cloud: a set of scanned 3D points used as the geometric reference.

Scope boundary

The client wanted the aluminum extrusion press and its conveyor system. Surrounding structures and unrelated equipment were excluded.

Problems and responses

Problem Response
MEP estimate based on exterior images only Compare with similar completed projects, weigh MEP density, ask the client for more object information
Poor point cloud quality in dense machinery areas Use client images next to the scan data
One family for the full machine gave large, slow files Split into blocks: pulling motor, conveyor belt, stamping machine block
Export to another software format risked lost or distorted objects Research the export path and check display and appearance
Limited time for QA-QC on many MEP objects Multi-step inspection

QA-QC procedure

  1. Section checks.
  2. Navisworks checks.
  3. Analysis with a proprietary point cloud solution.
  4. Correction of every error the client reports.
  5. Final point cloud analysis before handover.

Notes

The source page gives more than one accuracy figure, so none is repeated here. The specification block states LOD 400, and this reference uses that value.
