Technical Reference: As-Built Revit Model of an 11-Floor Heritage Office Building (LOD 300)

This reference summarizes the technical parameters, workflow and quality controls of a heritage as-built modeling project delivered in Australia.

Project parameters

Parameter Value
Project code 151.AUS
Building type Heritage commercial and office
Location Australia
Floors 11
Total area approx. 2,900 m² (31,215 sq ft)
Period June to July 2020
Disciplines Architecture and structure
Level of Development LOD 300
Input Point cloud
Deliverable Revit file
Software Revit, Navisworks, internal tools
Accuracy target ±15 mm (±0.6 in) against the scan

Definitions

  • As-built BIM model: a model that records the existing condition of a building, derived from measured data rather than design intent.
  • LOD 300: a level of development where elements are modeled as specific, dimensionally accurate objects with defined geometry and placement.
  • Point cloud: a set of measured 3D points captured by scanning, used as the geometric reference for modeling.

Workflow

  1. Receive the point cloud and confirm the scope: architecture and structure for the full building.
  2. Identify priority areas named by the client: the facade and selected interior locations, mainly columns and beams with heavy ornament.
  3. Model the base architecture and structure at LOD 300 in Revit.
  4. Model ornamental elements (moldings, columns, balustrades, window frames) at the finish requested.
  5. Review the Revit model against the point cloud in Navisworks at each phase.
  6. Correct deviations and deliver the Revit file.

Modeling challenges

  • Ornamental scale: small, delicate decorative work requires experienced modelers and specialist tools.
  • Non-uniform detail: nominated locations require more detail than the rest of the building, which must be planned in advance.

Quality control

Phase-by-phase comparison in Navisworks keeps the model tied to the scan. The tolerance of ±15 mm applies to the model relative to the point cloud. Reviewing at each phase, rather than once at the end, limits the cost of correcting errors.

Uses of the result

The model supports study, conservation, restoration and renovation design. Its data can also be used for asset assessment and maintenance planning.
