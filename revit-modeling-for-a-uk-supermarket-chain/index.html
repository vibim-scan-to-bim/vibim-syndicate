Technical Reference: Project 661.UK Supermarket As-Built Model

This page records the specification, constraints and workflow of an as-built BIM model for a UK supermarket. It is a reference sheet, not a narrative.

Specification

Item Value
Project code 661.UK
Location United Kingdom
Sector Supermarket / Retail
Total area 14,000 m² (150,700 sq ft)
Floors 2
Disciplines Architecture, structure, MEP
LOD LOD 300 to LOD 400
Accuracy ±15 mm (±0.6 in)
Inputs Point cloud, 2D drawings
Deliverable Revit file
Software Revit, Navisworks, internal tools
Production window 19 July to 16 August 2023 (four weeks)
Program One of seven stores, April to August 2023

Definitions used in this project

  • Geometric data: the shape, size and position of each modeled object.
  • Non-geometric data: names, specifications and material information attached to objects.
  • Client family library: the set of Revit families supplied by the client. New components are built in place or edited only when nothing suitable exists.
  • Quality control batch: a scheduled review pass, run in groups so it does not interrupt modeling.

Constraints

  1. All families come from the client library.
  2. Naming and specification follow the chain-wide standard.
  3. Work on this store runs alongside new stores and revisions to delivered stores.

Workflow

  1. Separate the work into three streams: new LOD 400 builds, urgent revisions, and batched quality control.
  2. Build new stores from standard libraries, basic elements first and complex details last.
  3. Gather revision requests for delivered stores into larger batches.
  4. Trace each error to its cause (scan data, family or requirement) before fixing it.
  5. Feed the finding back into the standard.
  6. Apply the internal renaming tool to remove manual naming errors.
  7. Run the dedicated in-house sweep for missing objects, gaps and clashes, then repeat manual checks.

Outcome

The store was completed within its window. Handovers across the seven-store program stayed continuous. Reused and parametrized families sped up modeling, and the renaming tool saved production and quality-control time.
