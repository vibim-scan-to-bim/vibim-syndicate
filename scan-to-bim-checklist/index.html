Scan to BIM Checklist: A Technical Lookup for Scoping, Capture, Modeling and Handover

A Scan to BIM checklist turns a vague request ("model this building from scans") into a list of decisions that can be agreed, checked and signed off. This page works as a lookup sheet. It sets out what each phase takes in, what it produces, and which check closes it.

Definition

A Scan to BIM checklist is a structured list of tasks and requirements covering the work from laser scanning and point cloud processing to the validated Building Information Model. It also records the scope, deliverables and acceptance criteria the client has agreed to.

Phase lookup

Phase Input Output Closing check
1. Scoping Client brief, intended use Scope of work, target LOD, file formats, QC plan Client confirms scope in writing
2. Site preparation Site access details Scanner choice, station plan, permits Coverage plan covers obstructions and access
3. Capture Scanning plan Raw scans Every planned area has overlapping scans
4. Processing Raw scans One registered point cloud in .rcp, .e57, .pts or .las Alignment checked against control points
5. Modeling Registered cloud, LOD, naming rules As-built model with metadata Elements follow the agreed LOD
6. QA Model plus cloud Validated, purged model Deviations resolved, clashes cleared
7. Handover Validated model RVT, IFC, DWG, sheets, schedules, report Client review meeting held

Choosing the capture method

  1. Use a terrestrial scanner when accuracy matters most and time allows several setups.
  2. Use a mobile or handheld scanner when speed matters and geometry is tight or complex. Expect lower accuracy.
  3. Use drone LiDAR for large outdoor areas or places people cannot reach.

Definitions used in the checks

  • Registration: aligning separate scans into a single coordinate system.
  • LOD (Level of Development): how much geometry and data each element carries. It is fixed in phase 1 and tested again in phase 6.
  • Purge: removing unused families, views and elements so the file stays light.

Discipline add-ons

The seven phases stay the same. Only the focus changes.

  • Architectural: walls, openings, floors, ceilings, stairs and roofs. Confirm room dimensions and ceiling heights. State in the scope whether movable items such as office cubicles are excluded.
  • Structural: columns, beams, slabs and foundations. Verify member sizes and levels against the cloud.
  • MEP: ducts, pipes and equipment. Check routing and clearances, then run clash detection.

Practical notes

Teams working with new clients tend to use the full checklist to align expectations. Long-term clients often send only key requirements by email, so the supplier must read the project needs and define the scope itself. In both cases, the closing checks above stay the same, because they are what protect the model from rework.
