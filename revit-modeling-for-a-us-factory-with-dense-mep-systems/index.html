Project 508.US: Technical Reference for a Dense-MEP Factory Revit Model

Summary

Project 508.US is an as-built Revit modeling job for an industrial factory in the United States. This page lists the parameters, the constraints met in the machine room and the controls applied.

Definitions

  • As-built model: a model of existing conditions, not a design proposal.
  • MEP: mechanical, electrical and plumbing systems.
  • LOD 300: a level of development with accurate geometry for size, shape, location and orientation.
  • Clash detection: an automated check for elements that occupy the same space.
  • Point cloud: a set of scanned 3D points used as the geometric reference.

MEP systems in scope

  1. HVAC
  2. Plumbing
  3. Fire fighting
  4. Electrical
  5. Communication networks

Constraints observed

Constraint Effect on the model
Dense pipes, valves, pumps and sensors Overlapping points, hard to isolate single components
Humidity, low light, reflective metal Noise and occlusions in the scan
Similar-looking elements Pipes and conduits, or valve types, hard to tell apart
LOD 300 accuracy Small position errors can cause clashes later
Geometry-only input Equipment data must be added from other sources
Large data volume Needs strong hardware and data management

Procedure

  1. Split the machine room into modular zones.
  2. Clean the point cloud for each zone.
  3. Model each zone on its own, then merge it into the master model.
  4. Run Navisworks clash checks during the work, not only at the end.
  5. Classify major M&E equipment and attach its technical data.
  6. Overlay the final model on the point cloud and review the deviation.

Outcome

The client received a connected as-built model in which all systems are linked and reflect site conditions. The model supports clash resolution before renovation and acts as an asset database for operations and maintenance.
