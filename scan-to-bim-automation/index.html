Scan to BIM Automation: Technical Reference

This reference summarizes how automated scan to BIM converts a point cloud into parametric BIM objects, which algorithms sit at each stage, and where manual work remains. It is a lookup document, not a tutorial.

Definition

Scan to BIM automation is the conversion of laser scan or photogrammetry point cloud data into BIM models using artificial intelligence, machine learning, and computer vision algorithms. In its current state it is a semi-automated process, not a one-click solution.

Five-stage pipeline

  1. Point cloud processing. Registration and cleaning of data from terrestrial laser scanners or mobile mapping systems.
  2. Semantic segmentation. Deep learning labels each point as wall, floor, ceiling, window, and similar classes.
  3. Feature extraction. Planes, cylinders, and edges are extracted and grouped into building components.
  4. Parametric object generation. Extracted shapes are mapped to native BIM families rather than static meshes.
  5. Human verification. Modelers check the automated output against the scan.

Algorithm reference

Stage Algorithm Role
1 ICP (Iterative Closest Point) Registers overlapping scans by minimizing distance between them
1 SOR (Statistical Outlier Removal) Deletes points that are statistically too far from neighbors
1 SLAM Builds the map and tracks scanner position in mobile mapping
2 PointNet++ Neural network designed for unstructured 3D point clouds
2 RandLA-Net Segments one million points in a single pass
3 RANSAC Fits planes (walls) and cylinders (pipes) while ignoring outliers
3 Hough Transform Picks out lines, circles, and cylinders, including long straight pipe runs
3 Region Growing Expands from a seed point across points sharing a normal vector
4 Template Matching Compares a cluster against a library of known shapes
4 NURBS Generates free-form surfaces for heritage or curved geometry
5 Heatmap deviation Colors the distance between model and point cloud
5 Clash detection logic Checks generated elements for interference

Tool types

  • ClearEdge3D EdgeWise: standalone extractor with a Revit import plug-in.
  • Aurivus: Revit plug-in that detects walls, pipes, and beams.
  • BricsCAD BIM: authoring software with a workflow its maker calls semi-automatic.

PointNet and KPConv are research architectures, not products.

Limitations

  • Occlusion: hidden elements cannot be reliably inferred.
  • Non-standard geometry such as heritage moldings and custom joinery.
  • MEP routing logic, for example slope on gravity pipes.
  • Scarce labeled training data.

LOD guidance

Automation alone suits LOD 200. LOD 350 to 400 requires significant manual refinement.
